## Implemented

- GPT-6 Luna standard pricing uses the dated snapshot in `benchmark/cw122b2p/pricing-2026-11-05.json`: short and long context, cached reads, 30-minute writes, 12-hour writes, and output. Cache-write categories are disjoint and use total write rates. Settlement rejects absent or contradictory telemetry; when the provider reports aggregate writes without TTL counts, it uses the captured request's single effective TTL and rejects mixed overrides. This runs through `RequestPermit::settle_with_request()`. Known-value tests cover explicit 30-minute and 12-hour settlement and the captured live usage values.
- The runner defaults to `NO_GO`. `--check` validates but does not claim or launch. `--run` requires a new, expiring authorization bound to the provider, model, endpoint, tier, runner/pricing/CW/Codex/bubblewrap hashes, exact credential-file SHA-256 and path, evidence/claim paths, one-request cap, deadline, ceiling, and explicit overrun-risk acceptance. The runner digest covers `smoke.py` and its local fault-control helper sources. A replacement key at the same path is rejected both by the runner and when the daemon loads the authorized credential bytes. Claims are exclusive, synced, and kept in persistent storage outside the evidence directory.
- The live route uses the existing `cw wrap` Codex adapter. The CW server receives a key-file path only; L0 Codex receives a dummy local bearer and isolated home. Ordinary `cw wrap codex` retains `OPENAI_API_KEY`. Bubblewrap verifies hidden host-home contents and the provider key, and rejects keys beneath executable trees mounted into the sandbox. The proxy requires the exact authorized OpenAI route, control token, session ID, unexpired authorization, and standard tier; it adds `service_tier=default` when Codex omits it and rejects any explicit non-standard tier. Only L0 traffic refuses redirects. The server checks expiry again immediately before dispatch.
- Evidence verification checks the actual provider response model and effective service tier. A model mismatch is a failed smoke; missing model, tier, or usage telemetry is inconclusive. OpenAI documents that `auto` can inherit the project tier and `default` uses standard pricing, so L0 requires the explicit `default` request tier and verifies the response reports it.
- Private evidence includes full request bodies, full egress bodies, capped response bodies with completeness markers, turns/usage, SpendGuard ledger, database, Codex event output, and Codex home. Missing artifacts remain explicit and make the result inconclusive. Evidence is never written into the checkout.
